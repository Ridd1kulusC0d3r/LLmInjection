## Принципы

1. **Наблюдавшиеся инциденты, техники, показанные в исследованиях, и лабораторные примеры не смешиваются.** Сборник джейлбрейков может подсказать тест, но никогда не докажет, что субъект применял технику.
2. **Вывод не равен подтверждению.** Если использование ИИ выводится из артефактов, запись так и говорит.
3. **Метки поставщиков не объединяются** в универсальные псевдонимы без свидетельств.
4. **Зрелость берётся из графа.** Каждая техника относится к одному из уровней: наблюдается в реальных атаках, раскрытая уязвимость, показано в исследованиях или нет связанных свидетельств; проверка не даёт полю разойтись с данными.

## Быстрый старт

```bash
make check         # линтер, тесты, проверка данных и аудит графа
make build         # граф, STIX, статический API, слои Navigator и графики
python scripts/query_intel.py search "prompt injection"
python scripts/osint_ioc.py report.md --enrich    # извлекает IOC; дополняет CVE данными CISA KEV и EPSS
```

Python 3.12, только стандартная библиотека.
