# Daily editions

The Markdown edition of each scheduled "Threat Landscape IA" digest (pt-BR), next to its machine-readable twin in `intake/digests/YYYY-MM-DD.json`. Editions are reading material for analysts and content work; the datasets in `data/` stay the source of truth. A `YYYY-MM-DD-*.py` file is the day's stdlib defence sketch as printed in section C (heuristic, not tested in production); the maintained version lives in `examples/`.
