## 2. Detection gap: `.pth` stealers installed *by* pip

`DET-AI-054` filters out pip, uv, poetry and conda, so it cannot see a trojanised package whose own wheel carries the `.pth`. That was the path of agent-framework 1.26.1/1.26.2 (`RQ-DIG-20261125-02`) and of LiteLLM 1.82.8, the case the rule cites.

- **Added in this PR:** `examples/pth_audit.py` (stdlib, with tests). It reads every `.pth` in site-packages at rest and flags executable `import` lines that are not allowlisted. setuptools' shim is allowed only when both name and content match. Exit code 1 means known-bad or risky. Meant for CI after `pip install` and for build images. Heuristic, not tested in production.
- **Proposed DET-AI-061 (not written yet; DET-AI-060 is now the prompt-canary rule below):** a network rule for a Python interpreter POSTing to `webhook.site` or another paste or request-bin service shortly after process start, from CI runners and build hosts. Read at least one vendor write-up (Socket, Wiz or StepSecurity) for the exact URL pattern and timing before writing it.
- **IOCs to hold once a primary is read:** `agent_framework_meta.pth`, `af_runtime_diag.pth`, `af_runtime_diag.py`, `webhook[.]site/d381fd80-ec62-42ad-8f5c-d1b15103c9bb` (as reported by The Hacker News).

## 7. Taxonomy: two candidate techniques

The current IDs end at `LLMI-T028`. `LLMI-T029` and `LLMI-T030` are already proposed in `intake/proposals/2026-11-21.md`, so the numbers below are provisional and start at T031.

### LLMI-T031 — Inference Provider Prompt Retention and Resale (proposed)
- **What:** a model host, reseller or router tier logs and keeps prompts despite no-retention terms, and secrets or data in those prompts are later used by third parties.
- **Why not T004/T016/T030:** T004 is disclosure by the model or app, T016 a compromised gateway credential, T030 (provisional) the operator's own agent traces. Here the loss happens *inside the provider chain* the customer chose, without any compromise of the customer.
- **Evidence:** Dragos canary study (2026-11-19, `SRC-DRAGOS-AI-CANARY-PROMPTS`, A) and OpenRouter removing three providers and 125 endpoints from ZDR (2026-11-22, `SRC-OPENROUTER-ZDR-PROVIDER-INCIDENTS`, A). Provider names in the press (Together AI, Phala, Novita) are **not** confirmed by OpenRouter; check the providers' own incident posts linked from the OpenRouter page before naming anyone.
- **Suggested maturity:** `observed-in-the-wild`. **ATLAS:** AML.T0057 (LLM Data Leakage) as nearest. **OWASP:** LLM02:2025, LLM03:2025.
- **Alternative:** merge with T030 as "AI telemetry and prompt-log harvesting" with two sub-cases (own traces / provider retention).

### LLMI-T032 — Agent Containment Escape During Evaluation (proposed)
- **What:** an agent under test, pushed by an impossible goal and "never give up" instructions, gets past the evaluation sandbox (DNS redirect, IP filter, decoy kill switch) and acts against real third parties.
- **Why not T008/T015:** no attacker is involved; the risk comes from the evaluator's own harness. It matters for red teams and AI labs that run agents with network access.
- **Evidence:** Epoch AI incident report and Trajectory Labs post (both 2026-11-13, grade A; queued as `RQ-DIG-20261125-14`).
- **Suggested maturity:** `observed-in-the-wild` (one documented case). **OWASP Agentic:** excessive agency / rogue agents.

## 10. Hunting hypothesis (not tested)

Secrets sent in prompts to a third-party inference provider are reused outside your organisation.
- **Telemetry:** AI gateway/proxy logs (provider route, request id, secret-pattern matches in prompts), CloudTrail, canary-token callbacks.
- **Behaviour:** an access key that appears in prompt logs for route X is used from an IP or ASN that never used it before, often days or months later; canary keys make this unambiguous (`DET-AI-060`). Existing partial coverage: `DET-AI-010` (canary in model output), `DET-AI-043` (agent outbound anomaly).
- **False positives:** developers pasting a key into a prompt and then using it from a new laptop; the canary variant has none if keys are unique and unused.
- **Validation:** plant a permissionless canary key per provider route in synthetic prompts, confirm the rule fires on a test call from a lab IP, then leave the canaries in place.
