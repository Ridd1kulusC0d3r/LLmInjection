# Proposals from digest LLMI-20261121

Status: **for analyst review**. Nothing here is in `data/` yet. Each item says what would change and on what evidence.

## 1. Taxonomy: two candidate techniques

The current IDs end at `LLMI-T028`. The numbers below are provisional.

### LLMI-T029 — Autonomous Vulnerability Discovery and Weaponization by Offensive Agents (proposed)
- **What:** an agent framework, given a goal but no target-specific exploit, finds a previously unknown flaw and uses it without a human in the loop.
- **Why not T015/T028:** T015 is about chaining tasks and T028 about operators speeding up tooling. Neither captures *discovery* of a 0-day by the agent.
- **Evidence:** Amazon Threat Intelligence, 2026-11-20. Cairn agents found and exploited a MONAI Label path traversal that AWS assessed with high confidence as a zero-day (`SRC-AWS-CAIRN-MONAI`, A). GTIG's `exploit_agent` patch-diffing pipeline is the n-day variant (already queued).
- **Suggested maturity:** `observed-in-the-wild`. **ATLAS:** AML.T0049 as the nearest match; no exact technique.

### LLMI-T030 — Agent Trace and Transcript Credential Harvesting (proposed)
- **What:** stored agent traces, tool-call logs or transcripts hold secrets and are used for initial access or lateral movement.
- **Why not T004/T016:** T004 is disclosure by the model or app. T016 is a compromised gateway. Here the logs themselves are the loot.
- **Evidence:** Cursor, 2026-11-13. A Fireworks-issued key exposed a bucket of coding-agent traces, some holding unredacted credentials, which led to the trojanized `Anthropic.claude-code` 2.1.312/2.1.313 in Cursor's marketplace cache (queued as `RQ-DIG-20261121-26`).
- **Suggested maturity:** `observed-in-the-wild`.

## 4. Hunting hypothesis (not tested)

An offensive agent framework probes an exposed AI research service. After it gets a file write, it plants a Python start-up hook.
- **Behaviour:** dozens of distinct API routes from one IP within minutes; an upload carrying `..`, `%2e%2e` or an absolute path; then `sitecustomize.py`, `usercustomize.py` or `*.pth` appears (`DET-AI-059`, `DET-AI-054`); then the train or run endpoint is called; then new egress from the service's Python process (`DET-AI-053`).
- **False positives:** package installs, image builds, authorised scanners.
- **Validation:** isolated lab with MONAI Label <= 0.8.5 and a harmless traversal to a temp directory.
