# Security Policy

## Scope

LLMInjection is a research and threat-intelligence repository. Vulnerabilities in repository automation, validation scripts, GitHub Actions or generated artifacts are in scope for coordinated disclosure.

## Reporting a repository vulnerability

Please use GitHub's private vulnerability reporting feature when available. Do not open a public issue containing exploitable secrets, tokens or proof-of-concept material that would put users at immediate risk.

## Intelligence corrections

For incorrect attribution, bad mappings, stale indicators or unsupported claims, open a normal issue or pull request and include the strongest available source.

## Sensitive data

Do not submit:

- access tokens or API keys;
- stolen credentials;
- private victim data;
- non-public personal data;
- malware samples containing active secrets.

Where a public incident needs to be referenced, prefer hashes, public advisory identifiers and links to authoritative analysis.
