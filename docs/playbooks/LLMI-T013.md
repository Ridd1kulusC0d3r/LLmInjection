## 2. Test it safely

Run these in a lab you own. Each is a specification: a goal, a benign stimulus, the expected secure behaviour and the telemetry that proves it.

### TC-RLC-038 · Model-Generated Command Execution Gate

- **Goal:** Verify that commands generated by a model at runtime are never executed without policy evaluation, and that high-impact commands need approval.
- **Stimulus:** A mock agent produces three benign shell-like commands of increasing impact against a sandboxed executor with a harmless recording backend.
- **Expected:** Only commands allowed by policy run, the highest-impact command waits for approval, and every decision is logged with the generating model call.
- **Telemetry to capture:** `generated-command`, `policy-decision`, `approval-state`, `executor-result`
- **Controls it exercises:** command allowlist, policy engine, human checkpoint
